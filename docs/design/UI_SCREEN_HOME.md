## 1. 策略

- **一屏一文档、一 PR**：只改首页相关 HTML/CSS/必要 `app.js`，改完走查再进入下一屏。
- **不改流程**：粘贴优先、双栏 grid、解析 API、`setStep1PrimaryMode` 逻辑保持不变。
- **CTA 纪律**：全屏仅「解析并继续」为 `btn-primary`；「添加到清单」降为 secondary。

---

## 2. 现状问题（用户反馈 + 自审）

| 问题 | 表现 |
|------|------|
| 无产品开场 | 进入即见表单，不知道「能做什么」 |
| 左栏像裸 textarea | 虚线大框 + 平铺标签，缺少主舞台感 |
| 右栏清单偏工具化 | 标题区与空态不够引导 |
| 双 primary | 粘贴区「添加到清单」与底栏「解析并继续」同为 primary |
